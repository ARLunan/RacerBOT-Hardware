# RacerBOT-Hardware
ROS2 Jazzy Ackerman drive package to load into a RaspberryPi RP2350 Pico2 based on the linorobot2 micro-ROS architecture package configuration, repo https://github.com/hippo5329/linorobot2_hardware.git and https://github.com/jimdinunzio/linorobot2_hardware.git .
This repository defines for the single target controller, the Pico 2 and does not have the other targets in the linorobot2 repositories. Design chassis is the Traxxas LaTrax Rally equipped with a RaspBerry PI 4 controller configured with Ubuntu 24.04/ROS 2 Jazzy / micro-ROS.
